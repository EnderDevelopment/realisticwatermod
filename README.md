# Minecraft Water-Reaction Mod

RealisticWaterMod is a Minecraft Java Edition mod for Fabric that adds localized splash and bubble particle reactions when entities move near or through vanilla water. It keeps Minecraft’s built-in water textures and fluid behavior; it does not add a separate water object or simulate new water physics.

## Install

1. Install Minecraft Java Edition 26.3 and Fabric Loader.
2. Download or build the mod JAR compatible with Minecraft 26.3 and your Fabric Loader installation.
3. Place the JAR in your Minecraft `mods` folder.
4. Launch Minecraft using the Fabric profile.

The mod also requires Fabric API and Java 25 or newer.

## Use

1. Start Minecraft with the mod installed.
2. Enter a world with the mod loaded.
3. Move an entity through or near water. Movement and vertical motion in water can trigger splash or bubble particles.

Water blocks retain vanilla behavior and textures. The mod does not add an item or block named “Realistic Water,” change water collisions, or provide a custom fluid simulation.
